We are preparing a hosted Open Health Sync: sign up, get an API key, and build on clean health
data without running Postgres, a raw store or provider developer apps yourself.

Nothing is open yet, and nothing on this page is a commitment. The plan:

- **The same API.** The hosted service is meant to run the open source server, so everything in
  these docs, from the [quickstart](/docs/quickstart) to the [API reference](/docs/api-reference),
  applies to it too.
- **Nothing to migrate.** Code written against a self-hosted instance should only need a new base
  URL and a new key.
- **Self-hosting stays first class.** The server stays free and open source under the AGPL. The
  hosted service is an option, not a replacement.
