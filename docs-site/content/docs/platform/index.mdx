The hosted Open Health Sync is open in private beta: sign in, get an API key, and build on clean
health data without running Postgres, a raw store or workers yourself. Developers join from the
[waitlist](https://openhealthsync.com/waitlist?utm_source=docs&utm_medium=docs&utm_campaign=platform),
by invitation, in small groups.

## What the beta gives you

- **A key in a minute.** Create a project and get its API key, shown once. During the beta:
  three projects per account, five keys per project.
- **Data on the first call.** One click adds a synthetic user with 30 days from six sources, so
  your first request already returns sleep, heart rate and steps.
- **A checklist that ticks itself.** First key, first call, first user, first data, first
  webhook, each with the command to copy.
- **The same API.** The hosted service runs the open source server, so everything in these docs,
  from the [quickstart](/documentation/quickstart) to the [API reference](/documentation/api-reference),
  applies to it: REST, FHIR R4, Open mHealth, exports, webhooks and the read-only MCP server.
- **A quickstart with your values.** curl, TypeScript and Python, already filled in with your
  instance's address.

## Before you join

- **Test data only, for now.** Real user data opens once data processing terms and the
  providers' production approvals are in place. Until then, use demo and synthetic users.
- **Free during the beta.** Pricing for later is not set, and nothing on this page is a
  commitment.
- **Nothing to migrate.** Code written against the hosted service moves to a self-hosted
  instance with a new base URL and a new key, and back.
- **Self-hosting stays first class.** The server stays free and open source under the AGPL. The
  hosted service is an option, not a replacement.
