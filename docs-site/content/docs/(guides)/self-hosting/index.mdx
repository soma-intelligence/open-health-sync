Open Health Sync is one Go binary, `ohs`, plus Postgres with the TimescaleDB extension. Raw
payloads go to a local folder or an S3 compatible bucket. That is the whole stack.

## Requirements

| | Minimum | Notes |
| --- | --- | --- |
| CPU | amd64 or arm64 | Images and binaries are published for both. |
| Memory | 4 GB for the whole stack | A Raspberry Pi 5 with 4 GB runs it with the Pi overlay. |
| Postgres | 17 with TimescaleDB | Compose pins `timescale/timescaledb:latest-pg17` by digest. Only hypertables are used: no continuous aggregates, no compression policies. |
| Raw store | a writable folder, or an S3 bucket with `If-None-Match` | Writes are conditional and never overwrite. |
| Docker Compose | v2.24 or later | Only for the compose setups. |

## Versions

Releases are 0.x: any of them may change the API, the configuration or the schema. Images are
tagged with the version and with `edge` (the newest final release). There is no `latest` tag
while the version is 0.x: pin a version, and read the
[changelog](https://github.com/soma-intelligence/open-health-sync/blob/main/CHANGELOG.md) before
[upgrading](/documentation/self-hosting/upgrading).
