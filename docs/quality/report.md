# Quality score backtest

Model `2026-10-24.1`. Generated by `OHS_QUALITY_WRITE=1 go test -tags bench ./internal/quality/bench -run TestBench -v`;
see [docs/quality.md](../quality.md) for the method. Leave one subject out: every figure is scored by a residual
model and conformal factors fitted without its subject. Numbers only; only derived figures enter the repository.
