# Open Health Sync for Swift

Swift client for the Open Health Sync REST API, for iOS 15+, macOS 12+, watchOS 8+ and Linux
(client only), with an optional HealthKit sync for apps.

```sh
swift test                                   # unit tests, no server
OHS_URL=http://localhost:8080 OHS_KEY=ohs_sk_... swift run OHSExample
```

Guide: [docs/sdks/swift.md](../../docs/sdks/swift.md). Licence: MIT ([sdks/LICENSE](../LICENSE)), unlike the server.
