# open_health_sync (Dart and Flutter)

Dart client for the Open Health Sync REST API, for Flutter apps (iOS, Android, desktop, web) and
Dart backends. A plain Dart package: add it to a Flutter app by path or git. Version 0.1.0, not
published (`publish_to: none`). MIT licensed ([LICENSE](../LICENSE)).

Guide: [docs/sdks/flutter.md](../../docs/sdks/flutter.md). Overview of all SDKs:
[docs/sdks/README.md](../../docs/sdks/README.md).

```sh
dart pub get
dart test
OHS_URL=http://localhost:8080 OHS_KEY=ohs_sk_... dart run example/quickstart.dart
```
