# Open Health Sync for Kotlin

Kotlin client for the Open Health Sync REST API, for Android (API 26+) and the JVM (11+).

```sh
./gradlew test        # unit tests, no server
./gradlew runExample  # the quickstart, with OHS_URL and OHS_KEY set
```
